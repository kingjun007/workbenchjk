Personal mobile workbench (WorkBuddy), including daily news summary, stock &amp; gold financial information, Douyin hot topics, study notes archive, investment experience record, copywriting assistant and daily review storage, minimalist men's business style personal management tool.
# WorkBuddy 个人男士移动端工作台
## 八大功能分类
1. 📰 新闻热点：每日时政财经简讯汇总（股市参考）
2. 📈 每日股市资讯：盘面消息、行业动态实时摘抄
3. 🪙 黄金财经资讯：国际金价、宏观经济信息存档
4. 🔥 抖音热点话题：每日全网热门榜单记录
5. 📖 每日学习：个人学习感悟、知识笔记长期存档
6. 💰 投资专栏：炒股心得、资产配置思路记录
7. ✍️ 内容创作：短视频文案库 + 口播文案整理助手
8. 📝 每日复盘：创业、生活、投资总结归档

整体定位：简约商务男士自用知识库，云端永久备份、随时查阅。
